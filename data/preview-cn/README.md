# Aegis 先行测试卡中文翻译库

仅收录 Aegis 尚未提供原生中文的先行卡。**原生中文优先**，中文卡图及游戏判定均由 Aegis 处理。

## 数据文件

按编号系列分包，例如 `BT27.json`；结构为 `{ "schemaVersion": 1, "cards": { "BT27-070": {...} } }`。

字段 `name`、`form`、`attribute`、`types`、`main`、`optionEffect` 分别为中文卡名、形态、属性、类型、主卡面效果、选项卡面效果。双面卡的两个卡面分开保存。`translationStatus` 必须为 `community-preview` 才会被补丁采用。

目前已录入 `BT27-070`。其内容是基于 Aegis 规则实现及卡图截图核对的**社区先行翻译**，并非官方定稿。后续 BT27、EX14 的其余新卡必须核对原效果后逐张加入，不能批量臆测。

## 维护原则

- Aegis 已提供原生中文：插件不覆盖。
- Aegis 尚无中文且预览库已翻译：读取预览库补译。
- 未核实或未收录：保留原始文字，不伪造中文。
- 原生卡图与游戏规则由 Aegis 自身管理。
